# Diquark simulation cards

## Description

This repository contains [MadGraph](http://madgraph.phys.ucl.ac.be/) configuration files / run cards for generating background and signal event data sets for diquark scalar analysis, using Monte Carlo simulations.

If you find these files useful in your work, please cite [our paper in Phys. Rev. D](https://journals.aps.org/prd/abstract/10.1103/hxll-41ly).
