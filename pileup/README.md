# Minimum bias background generation (for pile-up simulation)

This directory contains configuration files and scripts for generating minimum bias background events using Pythia, for simulating [pile-up](https://www.lhc-closer.es/taking_a_closer_look_at_lhc/0.pile_up) at the LHC. Delphes can inject the generated files into each event, in order to simulate the effect of pile-up occurring naturally at the particle collider.
